# Передача заказа курьеру — дизайн поведения

## Цель

Убрать ошибку при передаче готового заказа и закрепить понятную ответственность: кухня готовит заказ, курьер самостоятельно принимает доставку и отмечает её завершение.

## Выбранная схема

### Клиент

Для доставки клиент видит короткую цепочку:

`Оформлен → Принят → Готовится → Передан курьеру → Доставлен`

Статус `Готов` клиенту доставки отдельно не показывается. Пока заказ ожидает курьера, клиент продолжает видеть спокойное сообщение о подготовке заказа. Для самовывоза статус `Готов` сохраняется как `Можно забирать`.

### Кухня

Кухня управляет заказом только до готовности:

`Новый → Принят → Готовится → Готов`

После статуса `Готов`:

- для доставки вместо активной кнопки показывается `Ожидает курьера`;
- для самовывоза остаётся действие `Выдан клиенту`;
- кухня не может переводить доставку в статус `Передан курьеру`.

### Курьер

Курьер видит оплаченные заказы с доставкой, включая готовящиеся заказы для планирования.

- У готового заказа показывается кнопка `Принять заказ`.
- Нажатие переводит заказ из `ready` в `courier`.
- После принятия показывается кнопка `Заказ доставлен`.
- Нажатие завершает доставку и закрывает заказ, чтобы клиент сразу получил статус `Доставлен` и возможность оставить отзыв.

## Серверная логика

- Переход `ready → courier` разрешён только роли `courier` и владельцу.
- Переход кухни `ready → courier` остаётся запрещённым.
- Финальное действие курьера должно атомарно завершать заказ: публичный результат — `Доставлен`, внутренний терминальный статус — `completed`.
- Повторное или устаревшее нажатие не меняет заказ второй раз: интерфейс обновляет карточку после ответа `409` и показывает понятное сообщение.
- Статус меняется в интерфейсе только после подтверждения сервера.

## Интерфейс и обратная связь

- Кнопки курьера имеют минимальную высоту 48 px и занимают доступную ширину карточки.
- Во время запроса кнопка блокируется и показывает `Сохраняем…`.
- При успехе карточка обновляется без перезагрузки.
- При ошибке остаётся прежний статус и показывается текст `Не удалось обновить заказ. Повторите ещё раз`.
- Двойное нажатие не отправляет два запроса.

## Совместимость

- Самовывоз не меняется.
- Существующие старые статусы `delivered` продолжают корректно отображаться как `Доставлен`.
- Отзывы остаются доступны только после терминального завершения заказа.
- Права владельца сохраняются.

## Проверка

Автоматические тесты должны подтвердить:

1. кухня не видит действие передачи доставки курьеру;
2. курьер может принять только готовую доставку;
3. курьер после принятия может отметить доставку завершённой;
4. самовывоз по-прежнему выдаётся кухней;
5. конфликт версии и двойное нажатие обрабатываются безопасно;
6. клиент видит утверждённые названия статусов;
7. завершённая доставка открывает форму отзыва.
